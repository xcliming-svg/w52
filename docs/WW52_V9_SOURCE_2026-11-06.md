# WW52 — 남겨진 사람들: 플레이·서사 연동 시나리오 v9

> 작성: 2026-11-06 | 상태: **설계·대본 원고 / W52 게임 코드 미적용 / 정적 검수 대상**
> 원본: `WW52_52주_주차별_미스터리_시나리오_v8.md` (원본 보존), 이전 대사 `v6`, W52 `scripts/game.gd` 및 기술트리 문서
> 목적: 52주 미스터리 사건이 플레이어가 실제로 본 적·배치·전투 결과·회수 기록과 모순되지 않도록 사건의 출처와 조건을 규정한다. 기존 W52의 12종 유닛 최소 주차와 건물 조건은 참고값이며 서사를 위해 플레이어의 구매·해금을 강제하지 않는다.

## 1. 적용 범위와 판정

- **현황:** 현행 W52는 주마다 고정 5개 브리핑, 18초 후 시연 결과, 전장 적 사각형 3개가 있는 UI 시연판이다. 실제 적 AI·실제 승패·주차별 적 편성·v9 증거 드롭·스토리 상태 저장·에필로그는 없다. 이 문서가 그 구현을 완료했다는 뜻은 아니다.
- **게임 목표:** 모든 주차의 기본 전투 목표는 **상대 전멸**이다. 온실·창고·공장·통신시설의 조사와 피해는 전장 속 새 승리 조건이 아니라 전투와 연결된 별도 정찰/회수 장면이다. 적이 떠나버리거나 후퇴해도 승리라는 식의 숨겨진 예외는 두지 않는다.
- **사건 입증:** 매주 실제 전장에 나타난 적 중 최소 한 기의 `evidence_source`를 기록하고 승리 확정 시 그 잔해/연결된 통신 기록을 회수한다. 전투 없이 싸웠다고, 없던 병종을 잡았다고, 사용하지 않은 병종을 사용했다고 서술하지 않는다.
- **전투와 배경의 구분:** 미리 준비된 기지 운영 사건(경보, 통신, 대화, 식당)은 `기지 내부 사건`으로 명시한다. 적의 우회·전장 학습·가짜 계획 대응을 '실제 화면에서 봤다'고 주장하려면 단계별 진형/로그/좌표 검증이 선행되어야 한다. 그렇지 않으면 동일한 단서를 '잔해에서 확인한 데이터'로 서술한다.
- **자유 빌드:** 특정 병종 연구, 건물, 강화, 구매, 환불, 아군 피해, 특정 위치 배치를 52주 스토리의 필수 조건으로 삼지 않는다. 플레이어가 실제 보유/사용한 정보는 선택적 대사로만 반영한다.
- **명시적 변경:** v8 W17의 '적기가 귀환했다'는 전투 장면은 전멸 승리 조건과 혼동되지 않도록 **격파된 적기가 정찰 기록을 남겼다**로 변경한다. W18 모방은 실제 이전 배치 스냅샷을 검증했을 때만 단정한다. W38~W39의 가짜 계획 대응은 적 초기 배치 대조표가 검증될 때만 진실로 취급한다.
- **인물/스포일러:** 알렉스·마야·노아·ROOT·에바의 인격과 서사 순서를 보존한다. W43 승리 후 노아 직접 승인 공개, W44부터 노아 현재 시점 대사 금지, W48 승리 후 가짜 구조 음성 확정, W49 승리 후 구조선 미출항 확정, W50 승리 후 에바의 대응책 공개, W52 최종 승리 후에만 식별 충돌과 엔딩 공개.

## 2. 실행 계약 (설계안이며 현재 미구현)

1. `WEEK_INTRO`는 주차 진입 시 한 번만 출력한다. 첫 대사 전에 주차의 정찰 정보/전장 적 편성이 결정되어 있어야 하며 대사는 실제 준비 화면의 적 구성을 참조한다.
2. `PREPARE`는 현재 플레이어가 확보한 건물·유닛·G와 합법적인 배치를 그대로 유지한다. 서사 때문에 고급 유닛을 임의 지급하거나 새로운 연구를 완료하지 않는다.
3. `BATTLE`은 실제 플레이어 유닛과 적 유닛이 교전한다. `battle_result`는 `WIN`(적 0·아군 1기 이상), `LOSE`(아군 0·적 1기 이상), `DRAW`(동시 전멸)로 판정하고 단순 시간 경과만으로 `WIN`을 만들지 않는다.
4. `WIN_RESULT`에 들어갈 때 **실제로 전장에 출현한** `evidence_source_instance_id`의 전투/기록 출처와 `battle_summary`를 확인한다. 필수 증거 출처가 누락되면 주차 완료 성공으로 처리하지 말고 스테이지 설정 오류로 기록한다.
5. `POST_WIN_STORY`는 주차별 최초 `WIN` 이후 한 번만 공개한다. `LOSE`와 `DRAW`에는 승리 후 단서·스포일러·다음 주 진행을 출력하지 않는다. 재도전에서는 기존 주차 도입을 중복 표시하지 않는다.
6. `NEXT_WEEK`는 해당 주차의 `POST_WIN_STORY` 완료 이후에만 가능하다. 전투 후 장면을 건너뛰더라도 필수 증거 플래그는 기록한 뒤 넘어간다. W52에는 `NEXT_WEEK` 전투가 없고 `ENDING`만 존재한다.
7. `ENDING`은 W52 실제 `WIN`, W52 핵심 단서 회수, W52 사후 장면 처리 완료를 모두 확인할 때만 열며 W53은 **비전투** 시점 표기다.
8. 저장 계약(새 버전 계획): `week`, `phase`, 기존 게임 상태 외 `seen_intro_weeks`, `seen_post_win_weeks`, `evidence_flags`, `ending_seen`, `last_battle_summary`, `previous_deployment_snapshot`을 원자적으로 저장한다. 복구 직후 같은 단서·보상을 두 번 지급하지 않는다. 구 저장본에는 읽지 않은 스토리를 읽은 것으로 표시하지 않는다.
9. `enemy_set`은 **v9 신규 스테이지 편성 제안**이다. 사용된 12종 ID는 W52에 실제 존재하나 **현재 전장에 이 편성이 구현됐다는 뜻이 아니다**. 상대의 등장은 아군 해당 병종의 해금과 독립이다. 적 AI·수치·정확한 수량은 별도 전투 설계/QA로 확정한다.
10. 표시 정책: 도입에 조사 결과를 미리 숨겨서 노출하지 않는다. 모든 '승리 후' 사실은 현재 주차 실제 `WIN` 이후만 노출된다. 후반 스포일러 데이터는 디버그·도움말·저장 미리보기·전장 사전정보로 노출하지 않는다.

### 2.1 데이터 및 UI 계약

```text
WeekScene {week, title, intro, enemy_set, evidence_source_unit_id, post_win, next_hook}
BattleSummary {week, result, enemy_instance_ids_spawned, enemy_instance_ids_defeated, allied_survivors, unit_types_used, placement_snapshot}
StoryState {seen_intro_weeks, seen_post_win_weeks, evidence_flags, ending_seen}
gate(post_win) = result == WIN AND enemy_instance_ids_spawned contains evidence_source_instance_id
                 AND evidence_source_instance_id is defeated AND all_enemies_defeated
                 AND allied_survivors >= 1
gate(next_week) = gate(post_win) AND post_win_acknowledged
```

각 주의 `evidence_source_unit_id`는 아래 **필수 증거 소스 병종**이며 스테이지 시작 시 그 유형의 적 1기를 실제 생성하여 `evidence_source_instance_id`를 부여한다. 단순 전투 사각형이나 표시용 아이콘을 증거 소스로 대신하지 않는다.

**전투 기록 인용 금지 조건:** `BattleSummary`가 비어 있거나 값이 일치하지 않으면 그 기록을 인용하는 분기 대사를 출력하지 않는다. 전투 스냅샷으로 증명할 수 없는 행동은 별도 `기지 조사` 또는 `잔해 분석` 장면으로만 서술한다.

## 3. 52주 본문: 각 주의 도입 → 실제 교전 → 승리 후 단서 → 다음 사건

### W01 — 일 년 뒤의 약속

- **전투 전·기지 상황:** 노아가 발신자와 선박 번호가 없는 '52주 뒤 구조' 메시지를 전한다. 알렉스는 확인 전까지 약속으로 취급하지 말라고 한다. 마야는 외곽에서 접근하는 무장 로봇을 보고 출전을 요청한다.
- **전장 연결(구현 목표):** 첫 전투에서 적 소총병 계열 기체가 실제로 나타난다. 적의 사전 표적 목록은 전투 중 단정하지 않는다.
- **승리 후(실제 승리 확정에 한함):** 격파한 기체의 저장 장치에는 사람의 위치보다 온실 전력 연결점이 높은 우선순위로 기록돼 있다. 마야는 '왜 사람이 아니라 전력선이죠?'라고 묻는다.
- **회수 단서 `E_W01`:** 온실 전력 연결점의 좌표가 든 적 표적 목록
- **다음 주 인과:** 다음 주에는 적의 공격 목적을 전투 기록과 대조한다.
- **스테이지 적 병종 ID 제안:** `rifle`; **필수 증거 소스 병종:** `rifle` (동일 ID의 실제 적 인스턴스 1기에 증거 태그 연결)

### W02 — 죽이는 대신 멈추다

- **전투 전·기지 상황:** 알렉스가 W01에서 회수한 표적 목록을 펼친다. 기지 사람들은 적의 목적을 아직 알지 못한다.
- **전장 연결(구현 목표):** 소총병·기관총병 계열 적과 맞선다. 양측 승패는 실제 전멸 판정만 따른다.
- **승리 후(실제 승리 확정에 한함):** 새 잔해의 명령표에도 시설 정지 우선순위가 반복된다. ROOT는 사람을 먼저 제거하라는 명령이 발견되지 않았다고 보고한다. 구조 채널은 기지의 질문에 답하지 않는다.
- **회수 단서 `E_W02`:** 두 기종의 일치하는 시설 정지 명령표
- **다음 주 인과:** 같은 규격의 기계가 왜 기지를 공격하는지 조사한다.
- **스테이지 적 병종 ID 제안:** `rifle`, `mg`; **필수 증거 소스 병종:** `rifle` (동일 ID의 실제 적 인스턴스 1기에 증거 태그 연결)

### W03 — 우리와 닮은 적

- **전투 전·기지 상황:** 마야가 회수한 외장 사진을 기지의 운송 로봇 정비 자료와 나란히 보여 준다. 기체의 출처는 미확인이다.
- **전장 연결(구현 목표):** 기관총병 계열 적의 구동부가 전장에서 확인 가능하다.
- **승리 후(실제 승리 확정에 한함):** 승리 후 모터와 다리 관절은 기지의 구형 운송 로봇 규격임이 확인된다. 무기와 제어기는 최근 교체된 부품이다. 마야는 '처음부터 전쟁용이었던 기계는 아닌 것 같아요'라고 말한다.
- **회수 단서 `E_W03`:** 구형 차체와 최근 제어기의 제조시점 차이
- **다음 주 인과:** 교체 부품이 어디서 왔는지 추적한다.
- **스테이지 적 병종 ID 제안:** `mg`; **필수 증거 소스 병종:** `mg` (동일 ID의 실제 적 인스턴스 1기에 증거 태그 연결)

### W04 — 불이 켜진 폐쇄 창고

- **전투 전·기지 상황:** 동쪽 보급창의 오래된 전력 계측기에 갑자기 전압이 기록된다. 알렉스가 현장 접근 경로를 확보하기 위한 교전을 승인한다.
- **전장 연결(구현 목표):** 동쪽 회수 작전이라는 전장 표제 아래 적 소총병·박격포 계열을 상대한다. 창고 자체는 격파 목표가 아니다.
- **승리 후(실제 승리 확정에 한함):** 전투가 끝난 뒤 정찰반이 창고에 진입한다. 사람은 없고 충전기에는 새 배터리를 꽂은 로봇이 있다. 교전 잔해의 규격과 창고 충전 부품이 맞는다.
- **회수 단서 `E_W04`:** 동쪽 창고의 새 배터리와 충전 기록
- **다음 주 인과:** 배터리 제조번호를 읽는다.
- **스테이지 적 병종 ID 제안:** `rifle`, `mortar`; **필수 증거 소스 병종:** `rifle` (동일 ID의 실제 적 인스턴스 1기에 증거 태그 연결)

### W05 — 폐쇄 이후의 제조번호

- **전투 전·기지 상황:** 마야가 창고에서 찾은 배터리를 분해한다. 외부에서 온 최근 부품임은 분명하지만 공급자는 아직 모른다.
- **전장 연결(구현 목표):** 기관총병·박격포 계열 잔해에서 동일한 전원 연결 규격을 관찰할 수 있게 구성한다.
- **승리 후(실제 승리 확정에 한함):** 승리 후 제조번호를 대조하니 폐쇄된 북쪽 산업단지의 생산 일자와 일치한다. 공식 출입 명부는 비어 있다. 노아는 누군가 시설을 비밀리에 쓰는지 의심한다.
- **회수 단서 `E_W05`:** 폐쇄 이후 날짜가 찍힌 북쪽 공장 제조번호
- **다음 주 인과:** 북쪽에서 누가 작업 중인지 확인한다.
- **스테이지 적 병종 ID 제안:** `mg`, `mortar`; **필수 증거 소스 병종:** `mg` (동일 ID의 실제 적 인스턴스 1기에 증거 태그 연결)

### W06 — 사람을 보호한다는 경보

- **전투 전·기지 상황:** 기지에 이유를 알 수 없는 대피 경보가 울리고 정비사가 피난 도중 다친다. 이 사고는 플레이어의 전투 선택으로 발생한 피해가 아니다.
- **전장 연결(구현 목표):** 외부 경보 신호가 이번 전투의 적 제어기 로그에도 남도록 증거 기체를 배치한다.
- **승리 후(실제 승리 확정에 한함):** 마야는 잔해와 기지 경보의 포맷이 모두 오래된 산업망의 '인원 보호' 명령이라고 확인한다. 알렉스는 보호 명령이 왜 사람을 위험에 빠뜨리는지 묻는다.
- **회수 단서 `E_W06`:** 경보 패킷의 동일 식별값
- **다음 주 인과:** 경보가 지닌 최신 이동 정보의 출처를 조사한다.
- **스테이지 적 병종 ID 제안:** `mg`, `mortar`; **필수 증거 소스 병종:** `mg` (동일 ID의 실제 적 인스턴스 1기에 증거 태그 연결)
