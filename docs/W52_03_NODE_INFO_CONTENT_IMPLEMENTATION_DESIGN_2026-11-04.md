## 1. 화면 상태와 공통 표시 계약
패널 전체는 01의 동일 고정 위치를 사용. 한 순간에 활성 컨텍스트는 하나:
- `TREE_BUILDING`: HQ/생산/기술시설 선택 → 이름·시설 효과·보유/해금/건설 상태.
- `TREE_UNIT`: 트리에서 병종 노드 선택 → 이름·기본 역할·주차·필요 시설·기본 병종 능력치(정의된 경우)·A/B 고유 강화 조회.
- `FIELD_INSTANCE`: 우측 전장에서 배치된 특정 개체 선택 → 이름+개체 식별·현재/최대 HP(정의된 경우)·사거리(정의된 경우)·현재 위치/배치 상태·기본 병종 역할·A/B 조회.

공통 화면 계층 (길면 내용 영역만 세로 스크롤):
1. 제목: 이름, 유형(본부/생산시설/기술시설/유닛), 현재 상태. 미래 해금 주차에는 '후보' 명시.
2. 역할 설명: 플레이어 의사결정에 필요한 1~2문장.
3. 해금/보유: 최소 Wxx vs 현재 Wxx, 선행 시설 명단 각자의 `보유/미보유`; 3개 이상도 줄 바꿈. 생산시설 보유와 해당 유닛 배치 가능을 구분.
4. 병종 관련 정보: 건물의 경우 생산·해금에 기여하는 병종; 유닛의 경우 전투 역할·능력치·고유 강화.
5. 하단 버튼: 04의 노출/활성 규칙. 비활성 이유는 짧은 문구로 설명.

불변 조건: 숫자 데이터가 없다면 `0`, `100`, `3칸` 등의 가상 값을 표시하지 않는다. 비활성 기능은 실제 가능한 기능처럼 보이게 하지 않는다. 노드 IDs, 수치, 상태는 `game.gd`의 단일 소스에서 계산한다.

## 4. 병종 능력치와 개별 유닛 상태
| 필드 | 트리 병종 선택 | 전장 개별 유닛 선택 | 데이터가 없을 때 |
|---|---|---|---|
| HP | 정의된 **기본 최대 HP** | 현재 HP / 최대 HP | 'HP: 미구현' |
| 사거리 | 정의된 기본 사거리, 단위 표기 | 적용 중인 사거리 | '사거리: 미정' |
| 공격력/공격주기 | 기본 정의 있을 때 | 실효 수치가 계산 가능할 때 | 해당 숫자 대신 '미정' |
| 방어/표적 유형 | 전투 모델이 제공할 때 | 개별 상태가 있으면 적용 값 | 숨기거나 '미정' |
| 개체 식별자 | 표시하지 않음 | 병종 이름 + 구분용 순번/ID | 생성된 `instance_id` 사용 |
| 전장 위치 | 표시하지 않음 | `grid_cell` 기반 행/열 | 위치가 없으면 표시하지 않음 |
| 현재 배치 수 | 병종별 수 / 전체 12칸 | 동일 병종 수 / 전체 12칸 | 배치 데이터에서 산출 |
| 강화 A/B | 조회 전용 | 조회 전용 | 가격·구매 상태 미표시 |

- 현재 W52의 전투는 타이머 기반 시연이며 실제 HP·사거리·공격력 자료가 없다. 구현 단계에서 가상 밸런스 값을 `game.gd`에 삽입하지 않는다.
- 숫자 표시용 함수는 실제 전투 데이터가 연결될 때만 유효 값을 제공한다. `current HP`는 전장 개체만 갖는 동적 값; `max HP`·사거리 등 기본 능력치는 병종 자료가 소유한다.
- HP 수치가 도입되면 0~max 범위 검증, max<=0 방어, 표기/막대 동기화 필요. 사거리 단위와 거리 판정(원형/격자 등)은 미정이므로 'N칸'을 가정해 공격범위를 그리지 않는다.

## 6. 구현 및 검증
1. `NODES`/`UPGRADES`를 단일 소스로 사용해 타입별 요약 모델/공통 정보창 데이터 구성. 별도 복제된 게임 규칙 테이블은 생성하지 않는다.
2. `buildings`, `week`, `phase`, `placements`로 실제 상태 평가. 버튼 활성은 04, 개체 ID/위치는 05에 위임.
3. 20노드의 이름·주차·필수 시설·역할, 강화 24항목을 원본과 정적 대조. 3개 요구 시설 줄 바꿈·스크롤·마지막 버튼 가시성 검증.
4. 결측 수치 미표시/미정, 개별 HP와 병종의 최대 HP 혼동 없음, 전투 조회 전용, 전체/기본 트리 및 저장 복구 회귀 검증.
5. 시연 수치와 미승인 정책은 확정 사실로 UI에 쓰지 않는다. 불일치가 있으면 설계-코드 대조 → 수정 → 재검사를 문서에 기록한다.

## 7. 의존성과 유보
- 01 고정 패널, 02 기본 HQ, 04 버튼, 05 개별 인스턴스 데이터와 연결되어야 최종 UI 검증 가능.
- 공식 전투 스탯 및 사거리 판정은 별도 승인/검증 전까지 조회 자리만 확보한다. 가짜 HP 숫자, 영구 유닛 소유, 강화 구매를 추가하지 않는다.
