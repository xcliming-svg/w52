## 1. 완료 기준

1. 기술트리는 정확히 HQ 1 + 생산시설 3 + 기술시설 4 + 유닛 12 = 20노드/화면 부모선 19개, 아래에서 위로 배치한다. 업그레이드 노드·선·배지는 생성하지 않는다.
2. HQ·로봇공장 기본 보유, 다른 건물은 부모 시설 보유 + 후보 최소 주차 조건 충족 시 버튼으로 즉시 보유 처리한다. 별도 건설 타이머는 없다.
3. 유닛은 후보 주차 AND 생산시설 보유 AND 추가 공유 기술시설 보유 조건으로 배치 가능하다. 다른 병종 연구를 요구하지 않는다.
4. 트리 기본 모드는 보유 시설과 그 바로 위 자식 예고만 보여 준다. 언제든 전체 20노드를 조회하고 동일한 조건으로 해금 상태를 확인한다. 교차 선행 시설은 상세 요건에서 표시한다.
5. 노드 도형은 육각 HQ(104), 각진 정사각 생산(88), 마름모 기술(80), 원형 유닛(72)이며 선택·호버 확대는 112% 한 번만 적용한다.
6. 유닛 클릭 시 별도 업그레이드 상세 영역에서 A/B 명칭과 제안 역할을 표시한다(12×2=24). 강화는 트리·연결선·아이콘/배지·보유 깊이에 영향을 미치지 않는다.
7. 기존 TreeClip 클리핑, 드래그 8px, 포커스 중앙, 최소 완전 노드+라벨 가시성, 배치/전투·도움말·대화·PC/Web 공통 동작을 유지한다.
8. 저장에 보유 시설을 추가하고 구 버전2의 주차/G/대화/도움말을 복구한다. 제거된 8노드 시연 병종 ID는 임의로 12종에 매핑하지 않는다. 구버전1은 계속 거부한다.

## 2. 구조 및 상태

- **단일 규칙 소유:** `NODES`(id/name/parent/kind/week/requires/position/detail), `UPGRADES`(유닛 ID별 A/B 효과 설명)를 `game.gd`에서 관리한다.
- 건물: `hq`, `robot_factory`, `walker_factory`, `armory`, `radar`, `drone_hangar`, `machine_shop`, `reactor`.
- 유닛: `rifle`, `mg`, `mortar`, `anti_tank`, `artillery`, `car`, `tank`, `destroyer`, `heavy`, `fighter`, `attacker`, `bomber`.
- 각 건물의 단일 `parent`는 시각적 화면선이며, 유닛 `requires`는 생산시설+추가 공유 기술시설이다.
- 보유 시설 `owned_buildings`는 영구 상태이며 주차 이동·배치 초기화와 독립된다. `full_tree_view`는 일시적인 UI 상태다.
- 건물 건설 시 : 입력 → 주차·부모 보유·중복·게임 단계 확인 → 보유 추가(동기, 대기 0) → 노드/팝업/배치 상태 갱신. 유닛 배치는 이미 존재하는 12칸 시연 규칙을 유지한다.
- 탐색 모드: `full_tree_view` 일 때 전체 표시. 기본 모드에서는 소유 시설과 그 직계 자식을 예고. 타 가지에서 요구하는 추가 건물은 선택 카드의 체크리스트로 알리며 선택 중에는 해당 경로도 임시 표시한다.
- 도형+라벨 실측 범위를 `_node_visual_rect`에 반영해 팬 카메라를 유효 위치의 합집합에 클램프한다. 라벨 기본 크기는 22px이며 멀리 떨어진 가지는 클리핑한다.

## 3. 미결정 정책과 시연 처리

- **건물 가격 미승인**: 0G는 확정 가격이 아니다. UI는 **"시연 건설(비용 미정)"**으로 표시하고 G를 차감하지 않는다. 최종 비용 확정 전에는 경제 밸런스와 건물 구매 가능 상태의 '돈 부족'을 검증할 수 없다.
- **유닛 생산 가격·스탯 미승인**: 기존 무료 배치 + 시연 전투 40G/보상 70G를 유지한다. 다른 병종 대비 성능·상성·전투 AI는 추가하지 않는다.
- **24개 강화 효과·가격·해금정책 미승인**: A/B의 명칭·제안 효과만 별도 정보 패널에서 조회 가능. 임의의 강화 구매·소유·전투 적용·환불을 구현하지 않는다.
- **주차 후보**: 문서의 W01~W40 값을 적용한 시연 판정임을 표기한다. 확정 규칙이 아니다.
- **건물 환불**: 교차 의존/미확정 환불 정책 때문에 추가하지 않는다. 저장된 건물 소유권을 일방적으로 되돌리지 않는다.
- **애니메이션**: 기존 포커스 보간은 유지하며 건물 건설 시 동기적으로 선/노드를 다시 표시한다. 문서상 선택 가능한 0.2~0.4초 선 성장 및 움직임 감소 설정은 별도 정책 확정 후 검토. 화면 분리나 신규 설정을 임의로 추가하지 않는다.
