# W52 UI 구현설계서 — 2026-11-02

상태: UI 규격과 상호작용 계약 확정. 52주 전투 AI, 각 주 기획 문구, 실제 경제 밸런스는 미확정이며 데모 값을 쓴다.
프로젝트: Godot 4.7.2, GDScript, PC/Web 공용 UI, 기존 타이틀·메인메뉴·설정·일시정지 구조 유지.

## 1. 해상도

- 논리 해상도 **1920×1080, 16:9**. 최초 창 크기 1280×720, 모든 씬은 동일한 좌표계와 공통 UI 토큰 사용.
- Godot 설정: viewport_width 1920, viewport_height 1080, stretch mode canvas_items, stretch aspect keep. 다른 비율은 좌우/상하 검은 여백을 둔다.
- 상단 왼쪽 (0,0,1376,84): 주차/G 값만 출력, W52·작전설계 삭제.
- 좌측 트리 (0,84,1376,892): 헤더·부제·범례 삭제, 루트에서 상향 성장.
- 좌측 도움말 (0,976,1376,104): 우측 전투 버튼 영역과 수평 및 높이 정렬, 주차 인덱스 숫자 제거.
- 우측 상단 (1376,0,544,84): 시계 mm:ss, 결합된 1×|2× 토글. '전투 시간' 텍스트 삭제.
- 우측 전장 (1376,84,544,652): 적군 상단/아군 하단, 진영 설명 및 격자 치수 텍스트 삭제.
- 우측 로그 (1376,736,544,240): 유일한 내부 스크롤, 기록 시간 접두사 삭제.
- 우측 전투 버튼 (1376,976,544,104): 준비/진행/결과에 따른 기능.
- 대화 오버레이 (28,778,1320,171): 대화가 있을 때만 표시. 트리 위 플로팅. Space 또는 대화 클릭으로 진행.

## 3. 스킬트리와 정보창

- 모든 노드 유형은 호버 시 기본 크기의 1.12배, 선택 시에도 1.12배. 중복 크기 효과 금지.
- **선택 노드 포커스**: 선택한 노드를 왼쪽 스킬트리 영역의 화면 중앙인 전역 좌표 (688,530)에 보간 이동한다. 중앙 노드를 보는 동안 트리의 먼 가지가 화면 밖으로 이어지는 것은 정상이며, 64px 여백이 항상 눈에 보여야 하는 것은 아니다. 선택 포커스에도 드래그와 동일한 극단 이동 제한을 적용하며 이 범위에서는 모든 노드의 화면 중앙 포커스가 가능하다.
- **드래그 패닝**: 스킬트리 내부의 빈 공간 또는 노드를 왼쪽 마우스 버튼으로 누르고 이동하면 트리 전체(노드·연결선·라벨)가 포인터 이동량만큼 함께 움직인다. 손을 놓으면 그 위치에서 멈춘다. 카메라 포커스 자동 보간 중 드래그를 시작하면 보간을 취소하고 현재 화면 위치부터 끌어간다.
- **클릭과 드래그 구분**: 누른 위치에서 8 논리 px 미만은 클릭으로 간주하여 노드 선택 기능을 유지한다. 8px 이상 움직이면 드래그로 확정하고 마우스를 놓아도 다른 노드가 선택되지 않는다. 드래그 중 노드 호버 강조는 중단한다.
- **드래그 이동 범위 — 트리 끝에 도달했을 때만 남기는 64px 여유**: 스킬트리 창 로컬 크기는 1376×892px이다. 드래그 방향에 따라 반대쪽 노드·선·라벨은 창 밖으로 나가도 되며 `TreeClip`이 잘라낸다. 다만 **트리 오른쪽 끝을 창 왼쪽으로 끝까지 밀어도 트리 가장 오른쪽 픽셀이 왼쪽 창 경계에서 64px 떨어진 위치에 남는다. 트리 왼쪽 끝을 오른쪽으로 끝까지 밀면 트리 가장 왼쪽 픽셀이 오른쪽 창 경계에서 64px 떨어진 위치에 남는다.** 상하도 동일하다. 최대 확대된 노드 반경과 실제 측정한 이름 라벨 크기를 포함한 `content` 경계를 사용한다. 카메라 오프셋 최소값은 `64 - content.end`, 최대값은 `창 크기 - 64 - content.position`이다. 따라서 현재 화면 중간이나 매우 큰 트리의 중앙 노드를 선택했을 때에는 64px 여유가 보이지 않아도 정상이다. 전체 트리를 항상 화면 안에 가두거나 축소하지 않으며, 극단 드래그 상태에서 **트리의 마지막 부분이 화면 밖으로 완전히 사라지지만 않도록** 제한한다.
- **입력 영역 분리**: 대화창, 노드 정보 패널과 배치 버튼, 주차/G 헤더, 도움말, 우측 전장은 드래그 시작 영역이 아니다. 스킬트리 노드/연결선/라벨은 `TreeClip`이라는 좌측 전용 `Control(0,84,1376,892)`에 **`clip_contents=true`**를 설정하고 반드시 그 **자식 `TreeArt` Control**에서 그려 클리핑을 보장한다. 그 결과 드래그·중앙 포커스·경계 도달 시에도 우측 전장·상단 헤더·하단 도움말로 그려지는 픽셀이 없다. 상위 `Game`의 배경 덮어그림만으로 경계를 구현하는 것은 금지한다. 정보창·대화창은 별도 전면 오버레이 레이어에서 표시하며, 입력 클릭 판정은 원래 전체 화면 좌표를 유지한다.
- 선택 경로는 기존 연결선의 색상을 청록색으로 변경한다. 기존 연결선 위에 별도 선을 덧그리지 않는다.
- 노드 클릭 시 노드 옆 정보창에 이름·설명만 출력하고 유닛 노드에는 배치 버튼. 'UNIT NODE', '해금됨' 삭제.
- **정보창 정렬 보장**: 노드 정보창과 실제 배치 Button은 각각 좌표를 계산하지 않고 단일 `_popup_rect()`을 공유한다. 정보창은 390×274px, 배치 버튼은 정보창 좌상단 기준 (205,194)에서 정확히 160×62px. 공통 `UI.make_button` 생성 시 버튼별 `minimum_size`를 받아 즉시 설정해야 하며, 기존 메뉴 기본값(500×74px)을 만들었다가 나중에 줄이는 방식은 금지한다. 도움말 화살표(72×64), 배속 토글(103×52), 전투 버튼(505×74)도 동일 방식으로 생성한다. 대화 표시 중 정보창 y 상한은 480px, 그 외 670px으로 하여 배치 버튼이 카드 내부에서 벗어나거나 대화와 충돌하지 않는다. 드래그나 포커스 이동으로 정보창이 이동해도 같은 좌표계로 갱신한다.
- 팝업은 트리/대화/바닥 경계를 벗어나지 않게 자동 위치 조정. 전장 아군 클릭은 해당 유닛 노드를 선택·포커스.

## 4. 대화·도움말·전투

- 매주 대사 약 5개, Space 진행. 특정 대사 종료는 노드 선택·해금·포커스 등 이벤트와 연계 가능. 시연판은 3번째 대사 종료 시 방패병 선택.
- 인물 초상 자리에 정식 이미지가 없으면 임시 아이콘 표시, 해설 시에도 같은 자리에 해설 아이콘. 종료 시 완전히 숨김.
- 도움말은 매주 1개씩 공개. 탐색은 1..현재 주차만 허용. 미래 도움말 버튼 비활성.
- 격자는 셀 46px, 1–13주 6×6, 14–26주 8×8, 27–39주 10×8, 40–52주 10×10(해금 주차 시연값).
- 전투 상단 속도는 붙은 단일선택 1×/2×. 전투 정보는 준비·배치·교전·결과를 텍스트로 나열하고 타임스탬프는 붙이지 않는다.
- 준비→전투→결과→다음 주, 52주 이후 최종 결과. 시작 중복 방지, 유닛 없음/G 부족 시 이유 기록.
- 시연 전용: 초기 160G, 전투 비용 40G, 전투 종료 보상 70G, 시연 관전 18초. 이는 실제 게임 밸런스가 아니다.
- 메인 메뉴로 나갈 때 주차/G/대화 진행/도움말/배치를 저장하고 이어하기에서 복구. 구 이동 데모 저장은 새 1주 상태로 전환.

## 5. 개발·검증·배포

1. GitHub 최신 main을 기준으로 feature/w52-build-first-ui 분리. main은 직접 수정하지 않음.
2. 공통 해상도·토큰/메뉴 규격, 새 Game Control 스크립트·씬, main 상태 연결·저장 변경.
3. 변경 파일과 시나리오 상태를 대조한 정적 검사, GitHub Actions Godot 헤드리스 씬 테스트(초기 위치·양방향 극단 드래그에서 끝 노드가 창 안쪽 64px 위치에 남는지, 다른 가지의 화면 밖 클리핑 허용, 중앙 노드 포커스, 8px 클릭 임계값·정보창/버튼 정렬·트리 오버레이 속성 검사)와 Web Export 후 필요 시 수정 반복.
4. 확인된 이 기능 변경 파일만 devel에 반영, Pages 개발 주소 확인.
