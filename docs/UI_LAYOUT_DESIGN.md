# W52 UI 현행 구현설계 — 640×360 DB32 픽셀 UI

- 기준: 2026-11-03 승인된 W52_PIXEL_UI_640x360_IMPLEMENTATION_DESIGN.md (저장소 외부).
- Godot 4.7.2 / GDScript / Compatibility. PC와 Web은 동일 프로젝트·씬·게임 로직을 사용한다.
- 기존 1920×1080 논리 좌표 설계는 현행 규격이 아니다. 기존 데모 전투·52주·저장 계약은 보존한다.
- 이번 변경은 독립 기능 브랜치의 작업이며 안정판 배포를 의미하지 않는다.

## 1. 픽셀 확대

- 논리 viewport 640×360. 1920×1080 실제 출력에서는 3배, 1280×720 기본 창은 2배.
- Godot 설정: viewport stretch mode, keep aspect, integer scale mode, Nearest texture filter. 비정수 창 크기는 검은 여백을 허용한다.
- y=0~35는 콘텐츠·테두리·장식이 없는 검은 빈 공간.
- 공통 경계식: boundary(row) = 36 + round(324*row/20). row 0/3/13/17/20 = y 36/85/247/311/360.

## 2. 일곱 메인 프레임

| ID | 기능 | 프레임 반열림 Rect2i |

| L1 | 주차 및 G | (4,40,441,42) |
| L2 | 스킬트리·노드 정보 | (4,89,441,219) |
| L3 | 도움말·이전/다음 | (4,315,441,42) |

| R3 | 유일한 스크롤 로그 | (452,251,185,57) |
| R4 | 상태별 전투 버튼 하나 | (452,315,185,42) |

- 공통 수직 분할 x=448, 인접 프레임 사이 배경 간격 7px.
- 프레임의 외측 2px·중간 4px·최내측 1px = 총 7px. 네 모서리 8px 절단은 정수 픽셀 계단.
- 모든 프레임 4개씩, 총 28개의 3×3px 나사. 외곽 모서리에서 나사 중심 오프셋은 ±6.5px.
- 프레임 안쪽 7px이 실제 콘텐츠의 경계. L2 TreeClip: (11,96,427,205).
- 플로팅 대화 F1: (4,251,426,43), 3px 직각 경계, 모서리 절단/나사 없음. R3 상단 y=251과 정렬. Space·대화 클릭 진행 유지.
- R1에는 시간, 시계, 배속, 1×/2× 및 대체 콘텐츠를 생성/표시하지 않는다. 전투 경과 시간은 내부 로직에서만 유지한다.

## 3. DB32 단색 그래픽

사용 색상: #000000, #323c39, #222034, #595652, #696a6a, #eec39a, #9badb7, #d9a066, #37946e, #847e87, #8a6f30, #8f563b, #663931.

- 금속은 불투명 단색 픽셀 밴드만 사용. 그라데이션/반투명 빛/blur/SVG/안티앨리어싱된 사선 금지.
- 트리 연결선은 선택/비선택 모두 1px, 색상만 다르게. 기존 8개 노드 관계와 원/마름모/사각형, 3px 경계, 클리핑, 선택/호버/중앙 포커스/드래그 유지.
- 기존 WOFF2/Nanum fallback을 재사용하며 글꼴 안티앨리어싱을 끈다. 작은 한글의 판독성은 실제 화면 검증 대상으로 남긴다.
- 전투 버튼은 R4 안쪽을 채우며 기본 #d9a066, 위쪽 #eec39a, 하단/우측 #8a6f30, #8f563b, #663931 단색 밴드만 사용.

## 4. 게임 동작 불변

- 1~52주, 160G 시작, 데모 전투 비용 40G/보상 70G/18초 진행, 5개 대화, 유닛 8개와 부모 관계, 배치 최대 12기 및 잠금 주차 유지.
- 주차별 6×6(1~13), 8×8(14~26), 10×8(27~39), 10×10(40~52) 격자. R2 내부에서 정수 셀 크기와 시작 좌표를 계산하고 그리기·클릭 판정을 공유.
- 드래그 임계값 3 논리 px; 종료 시 다른 노드 선택 금지. 극단 패닝·포커스 애니메이션 중에도 완전 노드+라벨 최소 하나 가시. 대화창 가림 영역은 제외한다.
- 도움말은 현재 주차 이하, 전투 중복 입력 차단, 준비→전투→결과→다음 주와 52주 완료 상태 유지.
- PC/Web 공통 타이틀·메뉴·일시정지·설정·음량·전체화면·저장 연결 유지.
- 저장 형식 버전 2의 week/g/phase/dialogue/help/placements 키 유지, 버전 1 거부. 트리 좌표는 저장하지 않는다.

## 5. 검증 계약

tests/w52_ui_smoke.gd는 7프레임·28나사·DB32·정수 배율 설정·클리핑·노드/팝업·전장 클릭·52주/저장을 검증하도록 갱신한다. 실제 Godot 실행 여부, Web Export/CI, FHD 픽셀 가시성·마우스 조작감은 별도 검증 상태로 기록한다. 과거 1920 기준 자동검사 성공을 이번 640 버전의 PASS로 재사용하지 않는다.
