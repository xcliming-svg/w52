# BURROW // HUNTER — 10시간 점진 성장 설계서 v1 (2026-11-07)

## 상태와 범위
이 문서는 `tree/` 독립 Godot 게임의 이번 변경 설계입니다. 기존 W52 루트 게임과 다른 Git 작업은 수정하지 않습니다. 기존 `CONTRACT.md`의 열차/사각레일 표현보다 **사용자의 최신 컨셉 및 화면/조작 요구가 우선**합니다. 엔진, 기존 121개 노드 ID, 36종 업그레이드, 14종 적 ID, 저장 필드는 유지하고 표현과 진행 조율을 최소 변경합니다.

## 핵심 콘셉트
**「굴 사이를 도망치는 벌레 vs 길목을 계속 순찰하며 잡는 사람」**. 중앙의 큰 굴에서 벌레가 나와 네 모서리의 탈출 굴로 달려갑니다. 알약(캡슐) 모양의 추적자가 네 굴 주변 순찰 경로를 반복하며 자동 공격합니다. 기존 객차는 추적자의 수집·장착 도구로 표현하고, 사각 레일은 철도 대신 희미한 순찰 흔적입니다. 벌레 모양은 기본 도형에 촉수/다리 또는 점 무늬를 덧대되 적 종류의 판별색과 AI를 유지합니다.

## 화면, 폰트, 레이아웃
- 게임 전체 기준 16:9 / 1920×1080, 1280×720. 임의 다른 화면비는 가로·세로 중 짧은 축 기준 letterbox.
- 상단 48픽셀 HUD 아래 **왼쪽 기술 트리 50% / 오른쪽 전장 50%**. 중앙 6픽셀 분리선은 표시만 하고 크기 변경은 하지 않습니다.
- Godot 공용 테마의 기본 글꼴을 **Noto Sans KR**로 설정합니다. SIL OFL-1.1 라이선스를 함께 둡니다. Web/Windows 빌드 전에 공식 Google Fonts 소스에서 font 파일을 내려받고 실제 Godot 리소스로 로드합니다. 라이선스: https://raw.githubusercontent.com/google/fonts/main/ofl/notosanskr/OFL.txt .
- 글꼴은 OS 기본 폴백만 믿지 않습니다. 다운로드나 임포트 실패는 배포 실패로 처리합니다. 로컬 실행 전에도 의존 에셋을 준비해야 합니다.

## 기술 트리: 루트 → 눈앞의 가지
- 총 121개: C000 루트 1, 12방향의 메인 가지 10개씩. 첫 화면은 C000과 각 방향의 첫 1개만 보입니다. 구입한 노드 및 **모든 직접 선행 조건이 이미 구입된 노드**만 표시합니다. 구매 재화 부족과 노출은 별개입니다.
- 각 줄기는 1→2로 뻗고, 2에서 3·4로 2갈래 분기합니다. 왼가지 3→5→7→9, 오른가지 4→6→8→10; 각 노드의 parent 직선만 보입니다. 방사 배치는 유지하되 안쪽 줄기와 바깥 잔가지는 서로 각도를 달리합니다.
- ID, 깊이 비용, 효과 ID는 유지합니다. 능력치 단계는 구매한 해당 가지 노드 **개수**로 합산합니다. 하위 가지 해금 후 구매해도 각 단계 효과 중복 적용이 없게 유지합니다.
- 노드 **한 번 클릭**: 정보창(효과, 선행조건, 비용, 현재 상태). **활성화 버튼**: `may_buy` 검사를 다시 거친 뒤 원자적으로 구매. 이미 구입했거나 TP/XP 부족하면 버튼 비활성. 빈 공간 드래그/휠 확대는 연구하지 않습니다.

## 10시간 지향 난이도 (측정 전 설계가정)
`p=clamp(경과초/36000,0,1)`; 일반 적(종류별 배율 적용 이전):
- 기본 생성률 `0.14 + 1.25*p^1.4` 개/초. 5분 단위 20초 동안에만 `1+0.18*p` 배의 아주 짧은 파동.
- HP `12*(1+18*p^1.35)`; 기본 이동속도 `13+26*p^1.2` px/초. 빠른 종류는 `speedMultiplier` 적용.
- 크기 배율 `0.78+0.70*p`; 시각 불투명도 `0.38+0.62*p`. 후반일수록 크고 진하고 빠르게 보입니다. 색각 모드는 알파만으로 구별되지 않게 기존 형태/표식을 병용.
- 플레이어 순찰속도 260px/초, 트리·특수 이벤트 보정 유지(적보다 훨씬 느리다는 초기 문제 완화).
- 0~49분 EN01, 50~99분 EN01~02, …, 550분 이후 EN01~12. 낮은 단계 적도 남기되 최근 해금된 적이 더 자주 출현. 각 종류의 AI/크기/형태는 원래 식별성을 지킵니다.
- 정예 경고 60분부터 매 60분(15초 전), 보스는 120분부터 매 60분. 300분 후 추가 정예 1종. 기존 5분마다 보스 발생을 폐기.
- 플레이 지속이 10시간 보장되거나 실제 재미·실시간 FPS가 확보됐다는 뜻이 아닙니다. 숙련도, 구매, 무기, 방벽, 저장 및 10시간 실시간 실행과 FPS는 별도 검증이 필요합니다.

## 구현 범위 / 완료 기준
1. `project.godot`, `app.gd`, 공용 폰트 및 배포 준비: 한글 폰트 실제 로드와 16:9 렌더.
2. `run_controller.gd`, `layout_splitter.gd`, `viewport_adapter.gd`: 분할 50:50.
3. `tree_nodes.json`, `tree_rules.gd`, `tree_panel.gd`, `tree_renderer.gd`, `tree_interaction.gd`: 두 갈래 가지, 부모 직선, 노출, 팝업, 활성화.
4. `balance_config.gd`, `spawn_scaling.gd`, `spawn_director.gd`, `enemy_system.gd`, `enemy_factory.gd`: 600분 ramp, 단계적 종류, 정예 경고/보스, 느린→빠른·옅은→진한.
5. `battlefield.gd`, `rail_renderer.gd`, `portal_renderer.gd`: 구멍·추적자·벌레 상징으로 치환.
6. **구현 검사 12회 + 테스트/수정 12회**: 소스의 경로·의존성·규칙·입력·경제·저장·폰트·CI를 독립적으로 검사하고 발견된 오류 수정 후 재검증. 필요시 GitHub Actions 헤드리스/Export 검사, 마지막으로 `devel` PR 병합 및 Pages `/w52/tree-devel/` 배포. 실제 브라우저 플레이는 별도 단계.

## 충돌·제약
